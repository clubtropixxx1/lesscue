# レスられ総研（lesscue.com）

―私はレス山さんを救いたい―　セックスレスの原因と解消法を、悩みの型ごとに集めたデータベース。

## 仕組み

- 記事と数値の元データは Notion の「レス記事DB」「レス数値DB」で管理する
- ステータスが「公開」の行だけがサイトに載る（未確認・見送り・博士メモは載らない）
- 記事DBの「数値出典」は調査リリースなど数値DBの出典専用。記事一覧・診断には出さないが、数値カードの出典名には使う
- `tools/build.py` が Notion の書き出しから `index.html`（TOP）・`article/index.html`（記事一覧）・`data/index.html`（データで見る）と `data/*.json`、`sitemap.xml` を生成する
- `/about/`（このサイトについて・所長あいさつ・4つの型・掲載の基準・免責事項・お問い合わせフォーム）。所長あいさつ本文は準備中
- TOP は診断・型・数字・おすすめ上位5記事・解決のヒントの順。型やヒントを押すと `/article/?type=…` `/article/?h=…` に飛んで絞り込む（視点・年代・タグの絞り込みも記事一覧ページ側）
- Notion の生データは `_notion/` に置き、Git には入れない（`.gitignore`）

## 更新手順

1. Notion で記事を追加・編集し、載せたいものをステータス「公開」にする
2. Claude に「サイト更新して」と頼む（または週次タスクが自動で実行する）
3. Claude が Notion から書き出し → `python3 tools/build.py` → コミット・プッシュ
4. 数分で lesscue.com に反映される

## 色のルール

- 基本色：ロゴ「レスられ」の黒 #1D2426、「総研」の紺 #4F5D8C、その中間のネイビー #364059（数字・人型・横棒・ボタン）
- 差し色の赤 #C62F3E は数字カード・診断の枠・週報の登録枠の上端の線だけ。それ以外には使わない
- 紺系は上の2色で打ち止め（3色目を足さない）
- おすすめ度の★は黄土色 #B7791F のまま
- 所長記事（Notionの「所長記事」にチェック）は★を出さず、ネイビー枠の「所長の考察」ラベルを出す。並び順は☆☆と☆の間（重み1.5）。おすすめ度は空欄、「運営より」も基本は空欄
- 保留：記事の種別ごとの色（6色）は、記事が増えた時点で見直す

## 型ごとのページ（/type/<slug>/）

- tsuma-kyohi（妻拒否型）／otto-kyohi（夫拒否型）／ryudo-funaka（流動的不仲型）／kanzen-funaka（完全不仲型）

- 記事0件かつ解説なしの型ページは noindex にしてサイトマップから外す
- TOPの型ボタン・診断結果・このサイトについての型の説明から、このページへリンクしている

## 運用ルール（2026-10-02 合意）

- 特定の型（誰が拒否しているか）に触れていない一般論の理論・解決策の記事は、便宜上「流動的不仲型」にする
- 解決のヒント：性別に関係ない行動（話し合う、スキンシップ、対話、外出など）は、記事が片方に向けて勧めていても「夫婦で」に入れる。「妻が」「夫が」はその人にしかできない行動だけ（髪型・メイク、家事育児、筋トレなど）。サイト側でも、同じヒントが複数の列にあれば「夫婦で」にまとめて表示する
- タグは「状況・背景」（産後、ED、海外、カップルなど）、解決のヒントは「行動」。「話し合い」「カウンセリング」のタグはヒントへ寄せて廃止予定（付け替えは博士がNotionで行う）

## 「参考になった」ボタン

- 各記事カードに出す読者のおすすめボタン。件数は Google Apps Script（`tools/like_counter.gs`）のスクリプトプロパティに「記事ID（NotionページIDの32桁）→件数」で保存する。個人情報は受け取らない
- 押したかどうかはブラウザの localStorage（lr_like）だけで管理。もう一度押すと取り消し。厳密な重複防止はしていない
- `tools/build.py` の `LIKE_URL` にウェブアプリのURLを入れると表示される。空欄なら非表示

## 免責事項・プライバシー（/policy/）

- 免責事項と、外部送信（Google Fonts／Google Apps Script／Web3Forms、GA導入後はGoogleアナリティクス）の説明。外部サービスを足したらここにも追記する
